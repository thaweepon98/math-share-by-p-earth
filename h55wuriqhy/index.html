การประมาณเชิงเส้นและอัตราสัมพัทธ์

ประมาณค่าด้วยเส้นสัมผัส • อัตราการเปลี่ยนแปลงที่สัมพันธ์กัน

📐การประมาณค่าเชิงเส้น

ใกล้จุด x = a เส้นสัมผัสอยู่ใกล้กราฟมาก จนใช้แทนกราฟจริงเพื่อประมาณค่าได้: dy = f′(a)·Δx และ f(a+Δx) ≈ f(a) + dy — ยิ่ง Δx เล็ก ค่าประมาณยิ่งใกล้ค่าจริง

f(a+Δx) ≈ f(a) + f′(a)·Δx
√ตัวอย่าง: ประมาณค่า √x ใกล้ a = 4
Δx
🧮ตัวอย่างการคำนวณ: ประมาณค่า √4.1
① เลือก a ที่ใกล้ 4.1 และหาค่า f(a) ได้ง่าย: a = 4, f(a) = √4 = 2
② หา f′(x) = 12√x แล้วแทน a: f′(4) = 12√4 = 14
③ Δx = 4.1 − 4 = 0.1
④ f(4.1) ≈ f(4) + f′(4)·Δx = 2 + 14(0.1) = 2.025
ผลลัพธ์: √4.1 ≈ 2.025 (ค่าจริง ≈ 2.0248 — คลาดเคลื่อนน้อยมาก)
💧อัตราสัมพัทธ์ (Related Rates)

โจทย์: หยดน้ำลงผิวน้ำ เกิดวงกลมกระเพื่อมขยายออก รัศมีเพิ่มขึ้นด้วยอัตรา 2 ซม./วินาที จงหาอัตราการเปลี่ยนแปลงของพื้นที่วงกลม เมื่อรัศมีเท่ากับ 60 ซม.

วิธีทำอัตราสัมพัทธ์ 4 ขั้นตอน:
1กำหนดตัวแปร: ให้ t แทนเวลาที่ผ่านไป, r แทนรัศมีวงกลม (cm), A แทนพื้นที่วงกลม (cm²)
2เขียนสมการเชื่อมโยงตัวแปร: A = πr²
3หาอนุพันธ์ทั้งสองข้างเทียบเวลา t (กฎลูกโซ่): dAdt = 2πr · drdt
4แทนค่าที่โจทย์กำหนด แล้วแก้หาคำตอบ: drdt = 2, r = 60 ⇒ dAdt = 2π(60)(2) = 240π cm²/s
