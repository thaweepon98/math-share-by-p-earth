จุด P คงที่บนกราฟ จุด Q ห่างออกไป h หน่วย เส้นตัด PQ มีความชัน f(x+h)−f(x)h — เมื่อ h → 0 จุด Q เลื่อนเข้าใกล้ P และความชันเส้นตัดจะเข้าใกล้ค่าคงที่ค่าหนึ่ง เรียกค่านี้ว่า อนุพันธ์ของ f ที่จุด x เขียนแทนด้วย f′(x)

f′(x) = limh→0 f(x+h) − f(x)h

⭕อนุพันธ์ของฟังก์ชันโดยปริยาย (Implicit Differentiation)

ฟังก์ชันโดยปริยายคือฟังก์ชันที่เขียนในรูป F(x,y) = c เช่นวงกลม x² + y² = 9 — หาอนุพันธ์ dydx ได้โดยหาอนุพันธ์ทั้งสองข้างเทียบ x แล้วใช้กฎลูกโซ่กับพจน์ y (เพราะ y คือฟังก์ชันของ x โดยปริยาย)

2x + 2y·dydx = 0
dydx = −xy
🎯ลากจุดบนวงกลม x² + y² = 9 ดูเส้นสัมผัสเปลี่ยนตาม
🧮ตัวอย่างการคำนวณ

หา dydx ของวงกลม x² + y² = 25 ที่จุด (3, 4)

① หาอนุพันธ์ทั้งสองข้างเทียบ x:   2x + 2y·dydx = 0
② แก้สมการหา dydx:   dydx = −xy
③ แทนจุด (3, 4):   dydx = −34
④ ผลลัพธ์: ความชันเส้นสัมผัสที่จุด (3,4) คือ −34

สรุปภาพรวม: อนุพันธ์คือลิมิตของความชันเส้นตัดเมื่อ h → 0 — กฎพื้นฐาน (กำลัง ผลบวก ผลคูณ ผลหาร ลูกโซ่) และกฎตรีโกณคือทางลัดที่มาจากนิยามนี้ทั้งหมด ส่วนฟังก์ชันโดยปริยายใช้กฎลูกโซ่แบบเดียวกันเพียงแต่ y ขึ้นกับ x อยู่ในตัว
