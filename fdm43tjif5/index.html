จุดวิกฤต • การทดสอบอนุพันธ์ • โจทย์ปัญหาค่าจัดสุด

🔺จุดวิกฤตและค่าสุดขีด

จุด x = c เป็นจุดวิกฤตของ f ถ้า f′(c) = 0 หรือ f′(c) หาค่าไม่ได้ — ค่าสุดขีดเฉพาะที่ (local extrema) จะเกิดที่จุดวิกฤตเท่านั้น (แต่ไม่ใช่ทุกจุดวิกฤตจะเป็นค่าสุดขีด)

การทดสอบอนุพันธ์อันดับ 1: ถ้า f′ เปลี่ยนจากบวกเป็นลบที่ c → f มีค่าสูงสุดเฉพาะที่ • ถ้าเปลี่ยนจากลบเป็นบวก → ค่าต่ำสุดเฉพาะที่
🖱️ลากจุดไปตาม f(x) = x³ − 3x ดูเครื่องหมาย f′(x)
x₀
ลากจุดบนกราฟได้ หรือพิมพ์ค่า x₀ ตรงนี้
🏡ตัวอย่าง: ล้อมรั้วให้ได้พื้นที่มากที่สุด

มีไม้ทำรั้วยาว 800 เมตร ต้องการล้อมรั้วเป็นรูปสี่เหลี่ยมผืนผ้าโดยใช้ตัวบ้านเป็นรั้วด้านหนึ่ง (ไม่ต้องใช้ไม้) จงหาพื้นที่มากที่สุดที่ล้อมรั้วได้

2x + y = 800  ⇒  y = 800 − 2x
A(x) = x·y = 800x − 2x²
A′(x) = 800 − 4x = 0  ⇒  x = 200
x (m)
สรุป: พื้นที่มากที่สุดที่ล้อมรั้วนี้ได้คือ A(200) = 80,000 ตารางเมตร (เมื่อ x = 200 m)
