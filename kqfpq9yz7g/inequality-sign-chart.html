ทำไมต้อง + − +

สื่อการสอนแบบโต้ตอบ • อสมการพหุนาม ม.4

🧪ลองแทนค่าดูก่อน

ลองใช้ (x+2)(x-1) เป็นตัวอย่าง ลากจุดสีเขียวบนเส้นจำนวนด้านล่าง แล้วดูว่าแทนค่า x ตรงนั้นแล้วผลคูณเป็นบวกหรือลบ

(x + 2)(x − 1)
🔄แยกดูทีละวงเล็บ

เครื่องหมายของผลคูณจะสลับ ก็ต่อเมื่อมีวงเล็บใดวงเล็บหนึ่งพลิกเครื่องหมายตรงจุดนั้น — (x+2) พลิกที่ x=-2 และ (x-1) พลิกที่ x=1

x < −2−2 < x < 1x > 1
(x + 2)−++
(x − 1)−−+
ผลคูณ+−+
สังเกต: แถวผลคูณจะพลิกเครื่องหมาย ทุกครั้งที่ผ่านค่าวิกฤต (−2 และ 1) เพราะมีวงเล็บหนึ่งตัวพลิก
🟰กรณีพิเศษ 1: กำลังคู่ไม่พลิก
(x − 1)²
x < 1x > 1
(x − 1)²++
ยกกำลังสอง (หรือกำลังคู่ใดๆ) ผลลัพธ์ไม่ติดลบเลย นอกจากจะเท่ากับ 0 พอดีตรงค่าวิกฤต จึงไม่มีการพลิกเครื่องหมาย
➖กรณีพิเศษ 2: หน้า x ต้องเป็นบวกก่อน

ถ้าวงเล็บหน้าตาเป็น (−x + 2) สัมประสิทธิ์หน้า x ติดลบอยู่ (ภาพในฝัน ข้อ 3 บอกว่าหน้า x ต้องเป็นบวก) ต้องคูณ −1 ตลอดทั้งสองข้างก่อน แล้ว "กลับเครื่องหมายอสมการ"

1
−x + 2 > 0
2
−x > −2 (ย้าย 2 ไปลบ)
3
x < 2 (หารด้วย −1 → กลับเครื่องหมาย!)
⚖️ถามมากกว่าเลือก + ถามน้อยกว่าเลือก −

เลือกเครื่องหมายด้านล่าง แล้วดูว่าช่วงคำตอบและจุดปลาย (ทึบ/โปร่ง) เปลี่ยนไปอย่างไร

ตัวอย่าง A (พหุนามล้วน): (x + 2)(x − 1) 0
➗ตัวอย่าง B (มีตัวส่วน)

ใช้เครื่องหมายเดียวกับด้านบน — สังเกตว่าจุด x = 1 (มาจากตัวส่วน) เป็นวงกลมโปร่งเสมอ ไม่ว่าโจทย์จะเป็น ≥ หรือไม่ก็ตาม เพราะทำให้ส่วนเป็น 0 ไม่ได้

ตัวอย่าง B: x + 2x − 1 0
โดเมน: x ≠ 1
🛠️ต่ออสมการเองแล้วดูผล

เลือกวงเล็บ (x − r) ได้สูงสุด 3 วง กำหนดค่า r กำลัง (1 หรือ 2) และตำแหน่ง (เศษ/ส่วน) ของแต่ละวง แล้วกดสร้างแผนภาพ
