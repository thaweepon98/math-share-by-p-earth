ภาคตัดกรวยที่ระนาบตัดตั้งฉากกับแกนกรวยพอดี

🔺ภาคตัดกรวยคืออะไร

ภาคตัดกรวย (Conic Section) คือเส้นโค้งที่เกิดจากการใช้ระนาบตัดกรวยกลม 2 กรวยที่ต่อกันที่จุดยอด (กรวยคว่ำ-หงาย) รูปร่างของเส้นโค้งที่ได้ขึ้นอยู่กับมุมเอียงของระนาบเทียบกับแกนกรวยเพียงอย่างเดียว

ลองลากแถบเลื่อนด้านล่างเพื่อปรับมุมเอียงของระนาบ (สีฟ้า) แล้วสังเกตว่าเส้นโค้งสีส้มที่ระนาบตัดผ่านกรวยเปลี่ยนรูปร่างไปอย่างไร — ลากบนภาพเพื่อหมุนมุมมองดูได้ด้วย

0° วงกลม

ลากบนภาพเพื่อหมุนมุมมอง 3 มิติ

📐นิยามวงกลม

วงกลม (Circle) คือเซตของจุดทุกจุดบนระนาบที่มีระยะห่างจากจุดคงที่จุดหนึ่งเท่ากับค่าคงตัวค่าหนึ่งเสมอ จุดคงที่นั้นเรียกว่า จุดศูนย์กลาง (center) และระยะห่างคงตัวนั้นเรียกว่า รัศมี (radius)

(x−h)² + (y−k)² = r²

สมการรูปแบบมาตรฐาน เมื่อจุดศูนย์กลางอยู่ที่ (h, k) และรัศมียาว r หน่วย

x² + y² − 2hx − 2ky + (h²+k²−r²) = 0

สมการรูปแบบทั่วไป — กระจายจากรูปมาตรฐานด้านบน

🎯องค์ประกอบของวงกลม
(x−0)² + (y−0)² = 4²

ลากจุดศูนย์กลาง C หรือจุด P บนเส้นรอบวง เพื่อดูสมการเปลี่ยนไป — หรือจะพิมพ์พิกัดด้านล่างก็ได้

✍️พิสูจน์สมการวงกลม

ให้จุด P(x,y) เป็นจุดใดๆ บนวงกลม และจุด C(h,k) เป็นจุดศูนย์กลาง ตามนิยามแล้วระยะทาง PC จะเท่ากับรัศมี r เสมอ ไม่ว่า P จะอยู่ตำแหน่งใดบนวงกลม

① นิยามPC = r
② สูตรระยะทาง√(x−h)² + (y−k)² = r
③ ยกกำลังสองทั้งสองข้าง → รูปมาตรฐาน(x−h)² + (y−k)² = r²
④ กระจายวงเล็บx²−2hx+h² + y²−2ky+k² = r²
⑤ จัดรูป → รูปทั่วไปx² + y² − 2hx − 2ky + (h²+k²−r²) = 0
📝แบบฝึกหัด: แปลงสมการทั่วไป → มาตรฐาน

โจทย์จะสุ่มให้สมการรูปแบบทั่วไป ให้เลือกสมการรูปแบบมาตรฐานที่ตรงกับวงกลมวงเดียวกัน
