การดำเนินการของเซต

ยูเนียน อินเตอร์เซกชัน ผลต่าง คอมพลีเมนต์ • สื่อการสอนแบบโต้ตอบ

🔀เลือกการดำเนินการที่จะดู
A ∪ B = { x | x ∈ A หรือ x ∈ B }

สมาชิกที่อยู่ใน A หรือ B (หรืออยู่ทั้งคู่)

⭕แผนภาพเวนน์ (เอกภพสัมพัทธ์ U)
ส่วนที่เป็นคำตอบ (ถูกระบาย)
ไม่ใช่คำตอบ
📖นิยามการดำเนินการของเซต

เมื่อกำหนดเอกภพสัมพัทธ์ U และเซต A, B ⊆ U การดำเนินการของเซตทั้ง 4 แบบมีนิยามดังนี้

🔗ยูเนียน (Union)
A ∪ B = { x | x ∈ A หรือ x ∈ B }

สมาชิกที่อยู่ใน A หรือ B (หรืออยู่ทั้งคู่)

✨อินเตอร์เซกชัน (Intersection)
A ∩ B = { x | x ∈ A และ x ∈ B }

สมาชิกที่อยู่ใน A และ B พร้อมกัน (ส่วนที่ซ้อนทับกัน)

➖ผลต่าง A − B (Difference)
A − B = { x | x ∈ A และ x ∉ B }

สมาชิกที่อยู่ใน A แต่ไม่อยู่ใน B (ตัดส่วนที่ซ้อนกับ B ออก)

➖ผลต่าง B − A (Difference)
B − A = { x | x ∈ B และ x ∉ A }

สมาชิกที่อยู่ใน B แต่ไม่อยู่ใน A (ตัดส่วนที่ซ้อนกับ A ออก)

🌗คอมพลีเมนต์ A′ (Complement)
A′ = U − A = { x | x ∈ U และ x ∉ A }

สมาชิกทั้งหมดในเอกภพสัมพัทธ์ U ที่ไม่อยู่ใน A

🌓คอมพลีเมนต์ B′ (Complement)
B′ = U − B = { x | x ∈ U และ x ∉ B }

สมาชิกทั้งหมดในเอกภพสัมพัทธ์ U ที่ไม่อยู่ใน B

💡 ลองสังเกต: กลับไปที่แท็บ "เลือกการดำเนินการ" แล้วกดสลับปุ่มไปมา ลองดูว่าส่วนที่ถูกระบายในแผนภาพตรงกับนิยามด้านบนของแต่ละแบบหรือไม่
