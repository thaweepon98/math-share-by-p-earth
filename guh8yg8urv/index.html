ภาคตัดกรวยที่ระนาบเอียงตัดผ่านกรวยข้างเดียวทั้งวง

🔺ภาคตัดกรวยคืออะไร

ภาคตัดกรวย (Conic Section) คือเส้นโค้งที่เกิดจากการใช้ระนาบตัดกรวยกลม 2 กรวยที่ต่อกันที่จุดยอด (กรวยคว่ำ-หงาย) รูปร่างของเส้นโค้งที่ได้ขึ้นอยู่กับมุมเอียงของระนาบเทียบกับแกนกรวยเพียงอย่างเดียว — ถ้าระนาบเอียงเล็กน้อยจนยังตัดผ่านกรวยข้างเดียวได้ครบทั้งวง จะได้ วงรี

ลองลากแถบเลื่อนด้านล่างเพื่อปรับมุมเอียงของระนาบ (สีฟ้า) แล้วสังเกตว่าเส้นโค้งสีส้มที่ระนาบตัดผ่านกรวยเปลี่ยนรูปร่างไปอย่างไร — ลากบนภาพเพื่อหมุนมุมมองดูได้ด้วย

25° วงรี

ลากบนภาพเพื่อหมุนมุมมอง 3 มิติ

📐นิยามวงรี

วงรี (Ellipse) คือเซตของจุดทุกจุดบนระนาบ ซึ่งผลบวกของระยะทางจากจุดนั้นไปยังจุดคงที่สองจุด (เรียกว่า โฟกัส, focus) มีค่าคงตัวเสมอ — ถ้า P เป็นจุดใดๆ บนวงรี และ F₁, F₂ เป็นโฟกัสทั้งสอง แล้ว PF₁ + PF₂ จะเท่ากันทุกจุด

ส่วนของเส้นตรงที่เชื่อมจุดยอดทั้งสองข้างที่ยาวกว่า เรียกว่า แกนเอก (major axis) ยาว 2a หน่วย ส่วนที่สั้นกว่าและตั้งฉากกับแกนเอกที่จุดศูนย์กลาง เรียกว่า แกนโท (minor axis) ยาว 2b หน่วย โดยที่ a > b เสมอ

(x−h)²p² + (y−k)²q² = 1

สมการรูปแบบมาตรฐาน เมื่อจุดศูนย์กลางอยู่ที่ (h,k) รัศมีตามแนวแกน x ยาว p หน่วย และรัศมีตามแนวแกน y ยาว q หน่วย (แกนที่ยาวกว่าคือแกนเอก)

c = √(a² − b²)   ,   e = c / a   ,   0 < e < 1

c คือระยะจากจุดศูนย์กลางถึงโฟกัส และ e คือความเยื้องศูนย์กลาง (eccentricity) — ยิ่ง e ใกล้ 0 วงรียิ่งกลม ยิ่ง e ใกล้ 1 วงรียิ่งแบน

🔗ลองเอง: ผลบวกระยะทางคงที่จริงไหม

ลากจุด P ไปรอบๆ วงรี แล้วสังเกตว่า PF₁ + PF₂ เปลี่ยนไปหรือไม่

PF₁ + PF₂ = 3.00 + 7.00 = 10.00 = 2a
🎯องค์ประกอบของวงรี
(x−0)²/5² + (y−0)²/3² = 1

ลากจุดศูนย์กลาง C หรือจุดปลายแกนเอก/แกนโท (Hx, Hy) — สลับกันเป็นแกนเอกได้เองถ้าลากให้ยาวกว่า หรือจะพิมพ์พิกัดด้านล่างก็ได้

✍️พิสูจน์สมการวงรี

ให้โฟกัสอยู่ที่ F₁(c,0) และ F₂(−c,0) และให้ P(x,y) เป็นจุดใดๆ บนวงรีที่ผลบวกระยะทางถึงโฟกัสทั้งสองเท่ากับ 2a หน่วยเสมอ (โดยที่ a > c)

① นิยามPF₁ + PF₂ = 2a
② แทนสูตรระยะทาง√(x−c)²+y² + √(x+c)²+y² = 2a
③ ย้ายข้าง ยกกำลังสอง4cx = 4a² − 4a√(x−c)²+y²
④ จัดรูปa√(x−c)²+y² = a² − cx
⑤ ยกกำลังสองอีกครั้ง แทน b²=a²−c²b²x² + a²y² = a²b²
⑥ หารด้วย a²b² → รูปมาตรฐานx²/a² + y²/b² = 1
